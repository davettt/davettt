# Hi, I'm David

I've spent over 20 years working in digital — everything from technical support and managing support teams, to product management, lead enablement, and helping small businesses get their web presence sorted. When AI coding tools came along, they completely opened the door for me to finally start building the software I'd always wished existed.

In my spare time, I'm building macOS desktop apps under [Tiong Creative](https://tiongcreative.com.au). I'm focused on creating calm, private tools that respect your time. Each app is a one-time purchase, or you can get every app with a yearly membership, and everything runs locally on your Mac.
